# RoomSwitcher

RoomSwitcher — нативная Windows-утилита для переключения полного набора
дисплеев и аудиовыхода одним нажатием из системного трея.

Текущая тестовая версия Core `0.7.0` уже включает:

- пользовательские сценарии;
- устойчивые идентификаторы дисплеев и аудиоустройств;
- выбор от одного до четырёх включённых дисплеев и аудиовыхода;
- нативное меню трея: сценарии, Ctrl + Пробел, живой статус активных экранов,
  HDR и громкости аудиоустройства;
- временное нативное окно настроек с отдельными разделами «Основные» и «Сценарии»;
- опциональный автозапуск с Windows и правило выбора сценария при запуске;
- опциональную фиксированную громкость в сценарии, включая 0% как «без звука»;
- переход из редактора сценария в системные настройки экранов Windows;
- настраиваемую глобальную горячую клавишу следующего сценария;
- пользовательские имена дисплеев и аудиоустройств.
- безопасный RDP-режим трея: только живой статус удалённой сессии и mute.
- WinUI-оболочку настроек с темой, русским/английским языком и выбором иконки сценария.
- сохранение JSON в `%LOCALAPPDATA%\sol669\Room Switcher Tray`;
- автономную сборку Windows x64 и маленькие update-only архивы.

> Расположение, разрешение, масштаб, ориентация и частота экранов остаются под
> управлением Windows.

Core рассчитан на конфигурации не более чем с четырьмя дисплеями в одном сценарии.

## Сборка

Требования:

- Windows 10 версии 1809 или новее;
- .NET 8 SDK;
- Visual Studio 2022 с инструментами разработки Windows-приложений либо
  эквивалентная среда MSBuild.

```powershell
dotnet restore Room-Switcher-Tray.sln
dotnet build Room-Switcher-Tray.sln -c Release -p:Platform=x64
```

Переключение аудиовыхода изолировано в `AudioDeviceService`, поскольку Windows
не предоставляет для этого поддерживаемого публичного API.

Подсказка у значка в трее содержит только имя активного сценария.
