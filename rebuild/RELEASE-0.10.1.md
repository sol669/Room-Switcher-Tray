# RoomSwitcher 0.10.1 — сборка для проверки

- Добавлены умеренные отступы сверху и под заголовком настроек, без вертикального центрирования. Общая сетка сохранена.
- «Настройки» использует штатный WinUI TitleTextBlockStyle; остальные размеры текста не изменены.
- Выбранный пункт навигации сохраняет акцентный фон и контрастные текст/иконку при наведении и нажатии.
- Очевидные повторяющие текст подсказки убраны. Полное название появляется только для обрезанного текста; иконки без подписи сохраняют пояснения. Задержка подсказок — 700 мс.
- Левые заголовки на странице «Имена устройств» выровнены по внешнему краю карточек, как на остальных страницах. Правый заголовок остаётся над полем имени.
- Добавлена утверждённая розовая иконка приложения: прозрачный фон, девять размеров ICO от 16 до 256 пикселей. Изображение не перерисовывалось. Иконки сценариев не изменены.

Обновление предназначено для установки поверх 0.10.0. Пользовательские настройки и сценарии не входят в архив и не заменяются.

Проверки без запуска приложения (PowerShell 7):

```powershell
./rebuild/tests/Verify-SettingsContract.ps1
./rebuild/tests/Verify-IconAssets.ps1 -AssemblyPath ./artifacts/verify-0.10.1/RoomSwitcherTray.dll
./rebuild/tests/Verify-AppIcon.ps1 -PublishPath ./artifacts/verify-0.10.1
```

Проверка отрисовки сценариев выполняется из полной папки сборки с зависимостями. Интерактивная проверка окна, наведения и системного трея остаётся за пользователем. Это локальная тестовая сборка, не опубликованный релиз.
