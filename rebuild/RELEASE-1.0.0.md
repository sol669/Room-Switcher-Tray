# RoomSwitcher 1.0.0

Первый стабильный релиз RoomSwitcher для Windows 10/11 x64.

## Что вошло

- Сценарии экранов, аудиовыхода и стартовой громкости; устройство звука не блокирует переключение доступного видеосценария.
- Честные статусы отключённых устройств, безопасное сопоставление аудиоendpoint и отсутствие подмены звука случайным соседним выходом.
- Настройки с системными и пользовательскими именами устройств, палитрой из 16 иконок, темой, языком, автозапуском и горячей клавишей.
- Текущий сценарий всегда первый и жирный в трее; Ctrl + Space использует сохранённый порядок сценариев.
- Отдельный безопасный режим RDP: «Удаленный сеанс», «Удаленный экран», «Удаленное аудио».
- Розовая иконка RoomSwitcher, отдельные монохромные индикаторы RDP и неполного сценария.

## Какой файл выбрать

- `Room-Switcher-Tray-Setup-Self-Contained-v1.0.0.exe` — рекомендуемый установщик: всё нужное уже внутри, подходит для установки без интернета.
- `Room-Switcher-Tray-Setup-v1.0.0.exe` — компактный установщик, при необходимости скачает официальные Microsoft .NET 8 и Windows App Runtime.
- `Room-Switcher-Tray-Portable-Self-Contained-win-x64.zip` — переносная версия со всеми зависимостями.
- `Room-Switcher-Tray-Portable-win-x64.zip` — компактная переносная версия, требует .NET 8 и Windows App Runtime 2.3.

Перед установкой закройте RoomSwitcher через пункт «Выход» в меню трея. Сценарии и настройки сохраняются отдельно и не удаляются обновлением.

## Проверки

- 128 автоматических сценарных проверок.
- 14 проверок идентификации и именования аудиоустройств, включая Steam Deck и общие ContainerId.
- 316 безопасных чтений Core Audio в нескольких потоковых режимах.
- Проверки интерфейса, иконок и результата self-contained publish.
