# RoomSwitcher 0.10.0

- Палитра из 16 согласованных иконок: сетка 4×4, подсказки, навигация клавиатурой и отдельный пункт «Литеры».
- В пункте «Иконка сценария» отображается слово «Литеры»; сами буквы редактируются в дополнительной строке.
- Литеры в трее: обычный Segoe UI без раздельного растяжения по осям.
- Обновление значка после успешного сохранения, независимо от страницы настроек. Изменение только имени/иконки не требует повторного применения устройств.
- «Имена устройств»: системные имена по умолчанию вместо заглушек; пользовательские имена сохраняются.
- Сценарий: имя и иконка → экраны → аудиоустройство и громкость. Параметры Windows вынесены в отдельную группу основных настроек.
- Сохранены прежние числовые идентификаторы иконок 0–4, существующие сценарии и настройки совместимы.

Иконки встроены в сборку (112 PNG: 16 изображений в 7 размерах). SVG и manifest находятся в `src/RoomSwitcherTray.Core/Assets/ScenarioIcons`.

Проверка без запуска приложения, PowerShell 7:

```powershell
./rebuild/tests/Verify-IconAssets.ps1 -AssemblyPath ./artifacts/verify-0.10.0/RoomSwitcherTray.dll
```

Проверяются размеры и прозрачность, чёрное/белое отображение, соответствие встроенным маскам, латинские/кириллические литеры, порядок палитры и совместимость идентификаторов. Интерактивное поведение WinUI и обновление системного трея требуют ручной проверки в приложении.
