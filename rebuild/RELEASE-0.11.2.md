# RoomSwitcher 0.11.2 — сборка для проверки

## Изменения

- Из настроек полностью удалены пользовательские всплывающие подсказки и класс QuietToolTip вместе с его таймерами. Именно отложенный показ был связан с воспроизводимыми вылетами при наведении на палитру; удалён весь этот путь выполнения.
- Палитра: штатный FlyoutPresenter с закруглением 8 и системной тенью, сетка 4×4 без постоянных плиток и рамок. Серое выделение при наведении, акцентное — у выбранного пункта. Выбранный пункт не меняет цвет при наведении. Сохраняются клавиатурный фокус и имена для экранного диктора.
- «Литеры» находятся под сеткой и показывают существующее встроенное поле ввода букв, без отдельного окна.
- Подсказка значка в системном трее сохранена: «Сценарий: Кабинет». Для RDP — «Удалённый сеанс (RDP)». При отключении устройств — «Не все устройства подключены», при ошибке применения — «Не удалось применить сценарий», при ошибке проверки — «Не удалось проверить устройства». Ошибка указывает на целевой сценарий. Для других отклонений сохраняется соответствующая причина, а не ложное сообщение об отключении.
- Громкость: ровно два режима — «Не менять» и «Установить громкость». Второй показывает отдельную строку «Установить громкость» с вводом целого числа 0–100. Невалидное/пустое значение нельзя сохранить. Новый сценарий по умолчанию не меняет громкость. Старые значения, включая 0 и 100, сохранены без изменения формата настроек.
- Громкость применяется только при применении сценария. Последующие изменения громкости или mute не создают предупреждений, не возвращают прежний уровень и не перезаписывают проценты в сценарии.

## Ручная проверка перед релизом

Установленное приложение при подготовке не запускалось и не заменялось. Проверки выше не заменяют проверку реального интерфейса:

1. Установить архив обновления поверх текущей папки после выхода из RoomSwitcher. Проверить версию 0.11.2.
2. Подержать мышь над кнопкой палитры и над каждой иконкой не менее 10 секунд, повторить открытие/закрытие. Проверить отсутствие подсказок и вылетов.
3. Проверить скругление/тень, чистую сетку, выделение, нижний пункт «Литеры», выбор мышью и клавиатурой, светлую/тёмную темы.
4. Проверить оба режима громкости, значения 0, 27, 63, 100 и запрет сохранения пустого/неверного ввода. Старые сценарии должны сохранить свои проценты.
5. Применить сценарий с громкостью 100%, вручную снизить её: предупреждения нет, сохранённое значение 100%, при повторном применении снова 100%.
6. Проверить подсказки обычного/частичного сценария и RDP, а также прежнее переключение экранов и звука. Физическое отключение и RDP в автоматических проверках не выполнялись.
7. При одновременно включённых полях литер и громкости страница может прокручиваться на небольшом экране; нижние кнопки остаются доступны.

Публикация релиза на GitHub не выполнена: сначала ручное тестирование и подтверждение.
