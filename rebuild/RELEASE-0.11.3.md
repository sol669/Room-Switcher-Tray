# RoomSwitcher 0.11.3 — сборка для проверки

## Изменения

- Исправлена навигация к существующим сценариям в настройках. После удаления подсказок условие ошибочно ограничивало подключение обработчика нажатия; теперь он подключается ко всем пунктам навигации.
- Текущий сценарий всегда первый в трее и выделен жирным. Остальные сохраняют относительный порядок; сохранённый список и цикл Ctrl + Space не переставляются. Команды меню сохраняют исходные идентификаторы.
- В RDP используются «Удаленный сеанс» и «Удаленный экран», без ё и суффикса (RDP).
- В колонке системных имён аудио показывается исходное имя endpoint, а не имя экрана. Пользовательские алиасы справа сохранены.
- Производное имя монитора допускается только для аудио типа Display при однозначной связи с экраном. Общесистемный/пустой ContainerId, несколько экранов или смешанные типы устройств не подтверждают такую связь. Несколько активных аудиовыходов и сохранённый отключённый выход не объединяются в один.
- Поиск аудио сначала учитывает точный endpoint во всех состояниях. Отключённый выбранный выход не заменяется активным соседом. Резервное сопоставление допускается только по однозначному физическому контейнеру, с учётом неактивных кандидатов; общий контейнер не является идентификатором устройства. Отсутствие звука по-прежнему не блокирует доступный видеосценарий.

## Проверки 2026-08-31

- 128 проверок сценариев: частичная доступность, отсутствие звука, безопасный выбор endpoint, HDMI-ожидание, громкость, порядок меню и неизменность цикла переключения.
- 14 проверок имён/видимости аудио на искусственных данных Steam Deck и общих контейнерах, без изменения оборудования.
- 316 успешных чтений Core Audio в трёх порядках создания объектов, STA/MTA. Никакие аудиопараметры не записывались.
- Статические проверки интерфейса и runtime; 224 рендера сценарных иконок, 6 образцов литер, 112 масок, 9 размеров ICO и 24 рендера состояний.
- Release publish Windows x64 self-contained выполнен. Единственное предупреждение NU1900 — недоступна сетевая проверка уязвимостей NuGet; зависимости не менялись.
- Актуальные App.xbf и RoomSwitcherTray.pri перенесены из результата компиляции. Содержимое архива сверяется по SHA-256.

## Ручная проверка

1. Выйти из RoomSwitcher, распаковать обновление поверх существующей установки и запустить вручную. Версия — 0.11.3.
2. На Steam Deck открыть оба уже созданных сценария, перейти в «Основные» и обратно; проверить мышь и сенсорный ввод.
3. В «Имена устройств» проверить системные «Динамики» и «Наушники» вместо двух ANX7530 U. Ранее заданные алиасы справа намеренно не переименовываются.
4. Проверить выбранный сценарий первым и жирным в трее, корректность нажатия каждого сценария и прежний цикл Ctrl + Space.
5. В RDP проверить новые подписи. В локальной сессии проверить отсутствие подмены отключённого аудиовыхода соседним и нормальную работу HDMI-аудио.

Установленное приложение не заменялось и не запускалось. Настройки, алиасы и сценарии пользователя не редактировались. GUI и физические подключения на Steam Deck ещё требуют ручной проверки. На GitHub не опубликовано.
