# Передача контекста: RoomSwitcher

Этот файл нужен, чтобы продолжить работу с RoomSwitcher в новом локальном чате Codex после переноса папки на другой компьютер. Сначала прочитать этот файл полностью, затем проверить `git status` и структуру репозитория. Не запускать установленный RoomSwitcher, не переключать реальные устройства и не менять пользовательский `settings.json` без явной просьбы.

## Проект и текущее состояние

- Windows WinUI 3 tray utility для переключения сценариев экранов и аудио.
- Рабочий исходный проект: `rebuild/src/RoomSwitcherTray.Core`.
- Рабочее дерево намеренно содержит незакоммиченные изменения нескольких итераций; не сбрасывать их и не удалять чужие файлы.
- Текущая тестовая сборка: **0.11.3**.
- Готовый архив: `artifacts/RoomSwitcher-Update-v0.11.3-win-x64.zip`.
- GitHub-релиз ещё не опубликован: сначала ручное тестирование новой сборки.
- Пользовательские настройки приложения не входят в архив и не должны заменяться. На домашнем ПК они находятся в `%LocalAppData%\\sol669\\Room Switcher Tray\\CoreRebuild\\settings.json`.

## Обновление 0.11.3

- Исправлен отсутствующий обработчик нажатия существующих сценариев после удаления tooltip. На Deck требуется ручная проверка навигации.
- Системные имена аудио берутся из endpoint.Name. DisplayName монитора назначается только Display-аудио при однозначном физическом контейнере; пустые/общесистемные контейнеры и неоднозначные связи исключены.
- FindAudio ищет точный endpoint во всех состояниях, не заменяет отключённый выход активным соседом. Резервное сопоставление не допускает неоднозначности. Алиасы и пользовательские настройки не менялись.
- Текущий сценарий первый и жирный в трее; исходные индексы команд и цикл Ctrl + Space сохранены.
- RDP: «Удаленный сеанс» / «Удаленный экран», без ё и (RDP). Это заменяет старые подписи в историческом описании 0.11.2 ниже.
- Пройдены 128 проверок сценариев, 14 проверок аудио на синтетических данных Deck, 316 чтений Core Audio, проверки ресурсов/иконок и Release publish. Подробности и актуальный ручной чек-лист — `rebuild/RELEASE-0.11.3.md`.
- Установленную программу не запускали и не заменяли. Компьютер не выключать: прежняя просьба о выключении относится к законченной итерации 0.11.2.

## Что уже реализовано до 0.11.2 (история)

- Палитра из 16 сценарных иконок: телевизор, ПК, ноутбук, схемы мониторов, геймпад, диван, колонки, наушники, проектор, микрофон, веб-камера, Deck, ПК со звуком. Выбор «Литеры» показывает встроенную строку ввода двух букв.
- Иконка приложения — розовая R с экраном. Для RDP есть отдельная монохромная иконка.
- В меню трея нет строки «Следующий сценарий» и галочки. Текущий сценарий выделен жирным; горячая клавиша показана у следующего доступного сценария.
- Трей показывает только устройства выбранного сценария, а не текущий резервный вывод Windows или устройства других сценариев.
- Сценарий применим, если доступен хотя бы один его экран. Пропавшее аудиоустройство не блокирует переключение. Нельзя подменять отсутствующее аудиоустройство произвольным текущим выходом Windows.
- Для частично применённого/ошибочного сценария используется предупреждающий треугольник; RDP имеет приоритет над обычной иконкой. Устройства различают «не подключён», «отключено в Windows» и ошибку чтения.
- Нет постоянного опроса оборудования: системные события дают одноразовое обновление. Ожидание HDMI ограничено и отменяется при смене намерения.
- В 0.11.1 устранён конфликт COM между чтением аудиоустройств и наблюдателем подключений. Общий `CoreAudioInterop` использует независимые RCW и не применяет `FinalReleaseComObject`.

## Изменения 0.11.2: ожидают ручной проверки

### Палитра и подсказки

- Из всего окна настроек удалён `QuietToolTip` и все пользовательские всплывающие подсказки. Ранее задержанный tooltip был главным подозреваемым в вылете палитры при наведении.
- Палитра использует штатный `FlyoutPresenter`: скругление 8 и системная тень.
- Сетка 4×4 плоская: у обычных иконок нет постоянных серых плиток/рамок; при наведении мягкий серый фон; выбранная иконка акцентная и не меняет цвет при наведении.
- «Литеры» перенесены под сетку. Нажатие открывает существующую встроенную строку, отдельного окна нет.
- Tooltip системного значка НЕ удалён: он остаётся единственным tooltip вне настроек.

### Подсказка системного значка

- Норма: `Сценарий: Кабинет`.
- RDP: `Удалённый сеанс (RDP)`.
- Частичное применение из-за устройств: `Сценарий: …` + `Не все устройства подключены`.
- Ошибка применения: `Сценарий: …` + `Не удалось применить сценарий`.
- Ошибка проверки: `Сценарий: …` + `Не удалось проверить устройства`.
- Для других отклонений отображается их причина; не называть все случаи «не подключён».

### Громкость

- Значение в сценарии — одноразовая инструкция при применении, а не постоянно поддерживаемый уровень.
- В списке ровно два режима: `Не менять` и `Установить громкость`.
- При втором режиме появляется строка `Установить громкость` с вводом целого числа 0–100. Допустимы 0, 1, 27, 63, 100. Пустое/некорректное значение не сохраняется.
- Новый сценарий по умолчанию: `Не менять`, `VolumePercent = null`.
- Старые проценты сохраняют смысл. При применении 100% устанавливаются; последующие ручные изменения громкости/mute не создают предупреждение, не применяют сохранённое значение повторно и не перезаписывают его. Следующее явное применение сценария снова использует сохранённый процент.

## Ручная проверка перед GitHub-релизом

1. Выйти из RoomSwitcher, распаковать обновление поверх установленной папки, запустить вручную и проверить версию 0.11.2.
2. Держать мышь над кнопкой палитры и над каждой иконкой 10+ секунд, много раз открыть/закрыть. Не должно быть подсказок и вылетов.
3. Проверить палитру в светлой и тёмной теме, скругление/тень, отсутствие плиток, подсветку, выбор «Литеры», клавиатурную навигацию.
4. Проверить оба режима громкости и ввод 0, 27, 63, 100; пустое и неверное значение не должны сохраняться.
5. Применить 100%, вручную изменить громкость: предупреждения нет, сохранённое значение остаётся 100%, при следующем применении снова 100%.
6. Проверить подсказки обычного/частичного сценария и RDP, а также обычное переключение экранов и HDMI-аудио.

## Правила работы

- Использовать `apply_patch` для локальных правок.
- Не выполнять `git reset --hard`, `git checkout --`, рекурсивные удаления и не трогать сторонние незакоммиченные изменения.
- Для поиска использовать `rg`.
- Не публиковать GitHub-релиз и не делать push без прямого подтверждения пользователя.
- Перед выпуском новой сборки обновлять версию в `.csproj`, `WinUiSettingsWindow.cs`, `Verify-AppIcon.ps1`, workflow и release notes; создавать новый архив, не перезаписывая старый.
